            2.7 Pharmacist Functional Requirements
The Pharmacist is responsible for managing medicines, maintaining medicine inventory and dispensing prescribed medications to patients. The system helps Pharmacists manage medicine stock, check medicine availability, monitor expiry dates, view prescriptions and maintain accurate medicine records.
Pharmacist Main Functionalities
1. Manage Medicine: The Pharmacist can add, update and delete medicine information, including medicine name, description, price and dosage so that medicine records remain accurate and up to date.

2. View Prescriptions: The Pharmacist can view prescriptions provided by doctors so that the correct medicines can be prepared and dispensed to patients.

3. Dispense Medicine: The Pharmacist can dispense prescribed medicines to patients so that patients receive the medications recommended by doctors.

4. Update Medicine Stock: The Pharmacist can update medicine stock information after receiving or dispensing medicines so that the system reflects the current quantity of available medicines.

5. Manage Medicine Inventory: The Pharmacist can manage medicine inventory by recording available quantities and newly received medicines so that the hospital maintains proper medicine supplies.

6. Search Medicine: The Pharmacist can search for medicines using their names or medicine IDs so that required medicine information can be found quickly.

7. Check Medicine Availability: The Pharmacist can check whether prescribed medicines are available in stock so that patients can be informed about medicine availability.

8. Monitor Medicine Expiry Dates: The Pharmacist can monitor medicine expiry dates so that expired medicines can be identified and prevented from being dispensed to patients.

9. Generate Medicine Reports: The Pharmacist can generate reports about available medicines, dispensed medicines and medicine stock so that the hospital can monitor pharmacy activities.

10. Notify Admin About Low Medicine Stock: The Pharmacist can notify the Administrator when medicine quantities become low so that necessary medicines can be restocked on time.

11. View Medicine History: The Pharmacist can view medicine transaction history, including received, dispensed and updated medicines so that previous medicine activities can be tracked.

12. Manage Medicine Categories: The Pharmacist can create, update and organize medicine categories so that medicines can be classified and managed easily.
